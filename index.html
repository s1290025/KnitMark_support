Knit Mark is a simple row and stitch counter for knitting and crochet.

How to use

  1. Create a project from the project list.
  2. Use the large buttons to count rows and stitches.
  3. Use Save Progress when you want to keep a temporary marker.
  4. Open History to review saved counts.
  5. Add notes to each project whenever you need them.

Contact

If you have a question, found a problem, or want to send feedback, please use the contact form.

Open Contact Form

Privacy

Knit Mark does not require an account. Project data, counts, history, notes, language, and theme settings are stored locally on your device.
